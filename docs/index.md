# Welcome to PulseDesk
 
PulseDesk is a customer-support application
that helps businesses manage customer queries.
 
## What you can do
 
- Create customer support tickets.
- Assign tickets to support agents.
- Track ticket status.
- Monitor support activities.
 
## Get started
 
See the [Getting Started](getting-started.md)
guide to configure your PulseDesk account.
