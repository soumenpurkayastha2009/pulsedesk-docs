
# Configure Notifications

Configure notifications to receive updates when support tickets change.

## Before you begin

Sign in to PulseDesk and open your user settings.

## Procedure

1. Open **Settings**.
2. Select **Notifications**.
3. Enable the notifications you want to receive.
4. Select **Save**.

## Verify the configuration

Confirm that your notification preferences are saved.

If notifications do not work as expected, see [Troubleshooting](troubleshooting.md).
